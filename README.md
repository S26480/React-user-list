# React User List

A responsive React application that fetches user data from the JSONPlaceholder API and displays user details in cards.

## Features
- Fetch user data using the Fetch API
- Display name, email, phone, city, and company
- Loading indicator while fetching data
- Responsive card layout

## Technologies Used
- React.js
- JavaScript
- CSS
- JSONPlaceholder API

## How to Run

1. Clone the repository.

2. Install dependencies:

   ```bash
   npm install

3. Start the development server:
    ```bash
    npm run dev

4. Open the local URL displayed in the terminal.
